# Kuantum_Rezonans
Atomların elektronlarının kuantum sıçramalarının NIST laboratuvar verilerini alıp ses dalgasına dönüştürür.
VS Code programını kurun.
Dosyayı açın, terminale gelip "pip install numpy scipy sounddevice" komutunu yazarak gerekli kütüphaneleri indirin.
Main.py dosyasına gelip F5 tuşuna basarak çalıştırın. Güle güle kullanın <3
